# Glossary

- Prometheus: collects and stores metrics, and evaluates alert rules.
- Alertmanager: groups, routes and silences alerts.
- Grafana: draws dashboards from metrics.
- node-exporter: exposes host metrics for Prometheus to scrape.
- Scrape: one request Prometheus makes to read metrics from a target.
- Recording rule: a precomputed query saved as a new metric.
