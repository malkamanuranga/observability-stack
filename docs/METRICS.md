# Metrics guide

- up: 1 when a target is reachable, 0 when it is not.
- node_cpu_seconds_total: CPU time per mode, used for CPU usage.
- node_memory_MemAvailable_bytes: memory available for new workloads.
- node_filesystem_avail_bytes: free disk space per filesystem.
- node_network_receive_bytes_total: bytes received per network device.
- node_load5: five minute load average.
